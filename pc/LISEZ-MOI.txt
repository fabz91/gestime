LOGICIEL GESTIME - CREATION DE L'INSTALLATEUR WINDOWS

Une seule fois :
  1. Installer Node.js (version "LTS") : https://nodejs.org
  2. Décompresser ce dossier, par exemple dans C:\horaires-pc

LE PLUS SIMPLE (sans taper de commande) :
  1. Installer Node.js (version LTS) : https://nodejs.org   (une seule fois)
  2. Double-cliquer sur CREER-INSTALLATEUR.bat
     Il fait tout seul "npm install" puis "npm run build" et ouvre le dossier "dist"
     qui contient l'installateur. Cela peut prendre plusieurs minutes.

Pour tester le logiciel :
  1. Ouvrir le dossier, cliquer dans la barre d'adresse, taper "cmd" puis Entrée
  2. Taper :  npm install     (quelques minutes, une seule fois)
  3. Taper :  npm start       (le logiciel s'ouvre)

Pour créer l'installateur (.exe) :
  1. Dans la même fenêtre, taper :  npm run build
  2. L'installateur est dans le dossier "dist" : "GESTIME Setup 1.0.0.exe"
  3. Double-clic dessus pour installer, une icône apparaît sur le bureau

Où sont les données ?
  Dans  %APPDATA%\GESTIME\donnees  (gestime-bredis.json, gestime-clamart.json),
  comme GESMAR et GESCOUNT. Le bouton "Dossier des données" l'ouvre.
  Sauvegarde automatique : chaque jour, un fichier GESTIME-AAAA-MM-JJ.json avec les
  deux magasins dans  %APPDATA%\GESTIME\donnees\sauvegardes  (60 jours gardés),
  réimportable par "Importer".
  Depuis la 1.2.0, l'ancien dossier %APPDATA%\Horaires est déplacé tout seul au
  premier lancement (connexion et données gardées), puis supprimé.

Si Windows affiche "Windows a protégé votre ordinateur" à l'installation :
  cliquer sur "Informations complémentaires" puis "Exécuter quand même".
  (Normal : le logiciel n'est pas signé.)

Mettre à jour plus tard : remplacer index.html, puis relancer "npm run build".
Les données ne sont pas touchées.
