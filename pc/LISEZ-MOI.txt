LOGICIEL GESTIME - CREATION DE L'INSTALLATEUR WINDOWS

Une seule fois :
  1. Installer Node.js (version "LTS") : https://nodejs.org
  2. Décompresser ce dossier, par exemple dans C:\horaires-pc

LE PLUS SIMPLE (sans taper de commande) :
  1. Installer Node.js (version LTS) : https://nodejs.org   (une seule fois)
  2. Double-cliquer sur CREER-INSTALLATEUR.bat
     Il fait tout seul "npm install" puis "npm run build" et ouvre le dossier "dist"
     qui contient l'installateur. Cela peut prendre plusieurs minutes.

Pour tester le logiciel :
  1. Ouvrir le dossier, cliquer dans la barre d'adresse, taper "cmd" puis Entrée
  2. Taper :  npm install     (quelques minutes, une seule fois)
  3. Taper :  npm start       (le logiciel s'ouvre)

Pour créer l'installateur (.exe) :
  1. Dans la même fenêtre, taper :  npm run build
  2. L'installateur est dans le dossier "dist" : "GESTIME Setup 1.0.0.exe"
  3. Double-clic dessus pour installer, une icône apparaît sur le bureau

Où sont les données ?
  Dans  %APPDATA%\Horaires\horaires-data.json
  Une copie de sécurité par jour est faite dans  %APPDATA%\Horaires\sauvegardes
  (les 30 dernières sont gardées). Le bouton "Dossier des données" l'ouvre.
  Le bouton "Exporter" crée un fichier à ranger sur une clé USB ou un cloud,
  et "Importer" le remet en place (ex. sur un autre PC).

Si Windows affiche "Windows a protégé votre ordinateur" à l'installation :
  cliquer sur "Informations complémentaires" puis "Exécuter quand même".
  (Normal : le logiciel n'est pas signé.)

Mettre à jour plus tard : remplacer index.html, puis relancer "npm run build".
Les données ne sont pas touchées.

Note : le logiciel s'appelle maintenant GESTIME, mais ses donnees restent dans
  %APPDATA%\Horaires (rien n'est perdu). Si l'ancien logiciel "Horaires" reste installe
  a cote, vous pouvez le desinstaller depuis Windows (Parametres > Applications).

Impression : le bouton Imprimer (dans Creation) ouvre la fenetre d'impression de Windows.
  Il faut utiliser les fichiers main.js, preload.js et index.html de la derniere version.
  La page hebergee par Claude peut bloquer l'impression : utilisez le logiciel PC.


Donnees incluses
  - Cette version contient deja les donnees BREDIS (export du 8 octobre) et CLAMART (plannings, conges, horaires interim, employes).
  - Au premier lancement de chaque magasin, elles remplacent les donnees locales ; l'ancienne copie est gardee dans le dossier de donnees (fichier ...avantmaj.json).
  - Ensuite, vos modifications sont conservees normalement.
